# رویداد آموزشی دادگستری شهریار × پژوهشگاه مواد و انرژی

سایت رسمی کارگاه **توانمندسازی کارکنان دادگستری شهرستان شهریار در مسیر تحول دیجیتال**  
هوش مصنوعی در رفع مشکلات اداری و بهبود بهره‌وری سازمان.

## اجرا

```bash
npm install
npm run dev
```

سپس در مرورگر: `http://localhost:5173`

## فونت مدام

فایل‌های woff2 را در `public/fonts/Modam/` با نام‌های مشخص‌شده در `public/fonts/Modam/README.txt` کپی کنید. تا آن زمان Vazirmatn به‌عنوان جایگزین استفاده می‌شود.

## پشته

Vite + React + Tailwind CSS + Framer Motion + lucide-react + HashRouter  
تم و توکن‌ها مطابق سیستم طراحی پورتال شفافیت MERC.
